01 Foundation

Your pass to what's on.

Everything in the interface serves one path: discover → choose → buy → experience. The event is the hero. ZoraPass is the frame around it — the yellow, the black, the stamp, the mono data. Campaign lines like ADMIT US. live in marketing and never appear in the product.

The stamp is the second mark

Default state: ZORAPASS. Status states (SOLD OUT, FEW LEFT, CHECKED IN) are used only when they are true. Always at −10°, never re-coloured, never on every card in a list.

07 Rules

Keep it ZoraPass.

Do

  • Let the event's artwork lead. ZoraPass frames it.
  • Say GET PASSES. One primary action per screen.
  • Show the true status, always, in words as well as colour.
  • Use mono for every number, code and time.
  • Offer groups where it helps: the stepper, the split, the invite.
  • Make the pass work offline, bright and one tap away.

Don't

  • Put ADMIT US. or TUKO WANGAPI? anywhere in the product.
  • Write "BUY NOW", "SUBMIT" or "LEARN MORE".
  • Set Bungee in a sentence, an error or body copy.
  • Invent colours, gradients, glows or decorative shadows.
  • Call the user a squad, or force group language on a solo buyer.
  • Show a status stamp that isn't true.
