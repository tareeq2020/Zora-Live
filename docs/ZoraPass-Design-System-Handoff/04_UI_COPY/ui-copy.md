# ZoraPass UI copy

Strings are part of the brand. Use these patterns, not improvised ones. Anything not listed here follows the rules at the bottom.

## 1. Buttons and links

| Action | String |
|---|---|
| Buy passes | **GET PASSES** |
| Browse | **FIND EVENTS** · **SEE ALL EVENTS** · **SEE WHAT'S ON** |
| Weekly / monthly views | **SEE THE WEEK** · **SEE THE MONTH** · **SEE THE WEEKEND** |
| Sold out | **JOIN THE WAITLIST** |
| Not on sale yet | **GET NOTIFIED** |
| Group checkout | **SPLIT WITH TUCHANGE** |
| Pass | **OPEN MY PASS** · **CHECK MY PASS** |
| Event day | **SEE THE PHOTOS** (after) |
| Organizers | **START SELLING** · **TALK TO US** |
| Product | **SEE HOW IT WORKS** · **GET THE APP** |

Never: BUY NOW · PURCHASE · SUBMIT · CLICK HERE · LEARN MORE (say what's there: SEE THE LINEUP) · BOOK NOW.

## 2. Status strings (the only ones that exist)

`NOW ON ZORAPASS` · `JUST ANNOUNCED` · `ON SALE` · `EARLY BIRD` · `PRESALE` · `LIMITED` · `FEW LEFT` · `ALMOST GONE` · `SOLD OUT` · `WAITLIST` · `FREE` · `WE'RE IN` · `CHECKED IN` · `LIVE NOW` · `NEXT UP` · `ZORA PICK` · `VERIFIED EVENT` · `TRENDING` · `NEW` · `POSTPONED` · `CANCELLED` · `VENUE CHANGE` · `TIME CHANGE`

Thresholds, so the words stay honest: FEW LEFT under 20% remaining · ALMOST GONE under 10% · SOLD OUT zero.

## 4. Group and payment strings

- "How many passes?" — never "How big is your squad?"
- "Me · Me +1 · Me +3 · The crew" for quantity presets.
- "One checkout for everyone going."
- "Split with Tuchange — each person pays their own share from their phone."
- "Everyone pays their share." / "Paid" / "Waiting on 2 people".
- Money: `TSh 25,000`, `From TSh 25,000`, `TSh 100,000 for 4`. Fees are always shown before payment: "All fees included." if they are.

## 5. Errors

Say what happened, then what to do. No codes in the main line, no blame.

| Case | String |
|---|---|
| Payment failed | That payment didn't go through. Try again, or use another method. |
| Network | No connection. Your pass still works offline. |
| Wrong OTP | That code didn't match. Check the message and try again. |
| Expired session | That took too long. Start again — nothing was charged. |
| Pass already scanned | This pass is already checked in. Talk to the desk if that's not right. |
| Sold out mid-checkout | The last passes went while you were paying. Nothing was charged — join the waitlist? |

## 6. Notifications (push, SMS, WhatsApp)

Short, useful, never more than one a day per event.

- On sale: "Afro House Rooftop is on sale. From TSh 25,000."
- Few left: "Few left for Friday. Get your pass."
- Day before: "Tomorrow. Doors 20:00 at The Terrace. See you inside."
- After: "Thank you, Dar. Photos from Friday are up."
- Waitlist hit: "A pass came back for Afro House Rooftop. It's yours for 20 minutes."

## 7. Rules

1. **No campaign language in product.** ADMIT US. and TUKO WANGAPI? never appear in the app, the website chrome, transactional emails, WhatsApp cards or notifications.
2. **Display type is caps and short.** Bungee lines are 1–4 words. Everything else is sentence case.
3. **Second person.** "Your pass", "You're in", not "The user's ticket".
4. **No exclamation marks**, except where a real person is quoted.
5. **No emoji in the interface.** Marketing may use them sparingly; the product does not.
6. **Numbers are mono**: dates, times, prices, counts, codes.
7. **City names in full in body copy** (Dar es Salaam), codes in mono labels (DAR).
8. **Swahili** is used where it's natural — Tuchange is a feature name, not a translation toggle. Don't invent slang.
9. **Never promise what the system can't do**: no "instant refunds" unless refunds are instant.
10. When in doubt, ask: does this sentence help someone get into an event tonight? If not, cut it.
